# Refactoring and Logging

These exercises give you a taste of what it means to "productionalize" code as you might see in an industry role.

## Exercise

- `refactoring_exe.py`: the exercise you will complete

- `refactoring_sol.py`: a reference solution that integrates logging

## Logging Utils

- `generate_sample_logs.py`:
  - a working example of how you can use the `logging_config.json` file
  - generates `sample_logs.log` in case you want to play with it or inspect it
  - simulates an app that spawns a database and an app that communicate where the app receives an API query
  - call `python generate_sample_logs.py` to generate the sample log

- `streamlit_log_viewer.py`:
  - view the generated logs via a [streamlit](https://streamlit.io/) app. You can use `pip` or `conda` install the streamlit package
  - start the server with `streamlit run streamlit_log_viewer.py`

- `sample_logs.log`: an example of what your logs **might** look like. Is generated by `generate_sample_logs.py`

- `logging_config.json`: an example logging config that we show you how to use in `generate_sample_logs.py`
