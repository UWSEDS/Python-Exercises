# Python-Exercises

Exercises following the [Python SWC course](https://swcarpentry.github.io/python-novice-inflammation/)

## Layout

A quick introduction to the files in this repository:

- `exercises.py`: contains exercises you should be able to solve after the SWC

- `optional.py`: contains optional exercises for those who are already more familiar with python and want a challenge.

- `refactoring.py`: code from [alan-turing-institute/bad-boids/](https://github.com/alan-turing-institute/bad-boids/blob/main/boids.py) that we've annotated with things to think about as you improve the code. The authors have a [github branch](https://github.com/alan-turing-institute/bad-boids/tree/better_boids/boids) with their recommended refactoring, but some of those concepts are far outside the scope of what we want to cover now. Having said that, feel free to take a look through!

- `python_wtfs`: a folder containing some wacky python exercises that will show you some unexpected ways that python can misbehave!

**Note**: some of these exercises are _hard_ and you shouldn't feel bad about taking a lot of time working on them. Struggling (productively) is a part of the learning process
